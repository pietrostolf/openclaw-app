Privacy policy

Last updated: October 14, 2026

claw is a personal connector used only by its owner to let a self-hosted OpenClaw assistant access the owner's own Google account.

Data accessed

With the owner's consent, claw accesses Google Calendar events and Google Tasks lists and tasks, using the Google Calendar API and Google Tasks API.

How data is used

  • Data is used only to show, create, and update the owner's own calendar events and tasks at the owner's request.
  • OAuth tokens are stored locally on the owner's computer and are never sent to any server other than Google.
  • No data is sold, shared with third parties, or used for advertising.
  • No data is collected from anyone other than the owner.

claw's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
